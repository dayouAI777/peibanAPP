# 在线升级发布说明

「升级后台」就是本仓库根目录的 **`version.json`**，不需要服务器、不需要数据库、不需要账号。

## 版本号在哪

- App 版本写在 `pubspec.yaml` 的 `version: 主.次.修+构建号`（例如 `1.1.0+2`）。
- 构建号（`+` 后面那个整数）是升级判断的**唯一依据**，必须严格递增。
- `package_info_plus` 在运行时读出 `version` 和 `buildNumber`，跟 `version.json` 的 `build` 比大小。

## version.json 字段

```json
{
  "version": "1.1.0",
  "build": 2,
  "apk_url": "https://github.com/dayouAI777/peibanAPP/releases/download/v1.1.0/app-release.apk",
  "changelog": ["改了什么，一行一条"],
  "published_at": "2026-11-13",
  "min_supported": "1.0.0",
  "force": false
}
```

| 字段 | 作用 |
|---|---|
| `version` | 展示给用户看的版本名 |
| `build` | 判断是否有新版；大于本机构建号才提示 |
| `apk_url` | 新 APK 的直链；为空时永远不提示更新 |
| `changelog` | 升级弹窗里列出的更新内容 |
| `force` | 预留字段，当前版本不实现强制升级 |

## 发一个新版，四步

```bash
# 1. 改版本号（build 必须 +1）
#    pubspec.yaml: version: 1.1.1+3

# 2. 编译
flutter build apk --release
# → build/app/outputs/flutter-apk/app-release.apk

# 3. 在 GitHub 建 Release：tag 用 v1.1.1，把 app-release.apk 作为 asset 上传，
#    文件名保持 app-release.apk（这样 apk_url 只换 tag 就能复用）

# 4. 改 version.json：version / build / apk_url 里的 tag / changelog / published_at
#    然后推仓库
git add pubspec.yaml version.json && git commit -m "Release v1.1.1" && git push
```

推完 `version.json` 的那一刻，所有已装的 App 在启动时（或设置页点「检查更新」）就会看到新版。

## App 端怎么读版本清单

`lib/services/update_service.dart` 用双源，谁通走谁：

1. `https://raw.githubusercontent.com/dayouAI777/peibanAPP/main/version.json`（直接拿原文）
2. 失败则退到 `https://api.github.com/repos/dayouAI777/peibanAPP/contents/version.json`（返回 base64，本地解码）

比对逻辑：`info.build > 本机 build` 且 `info.build != 已忽略的 build` 且 `apk_url` 非空 → 提示。
用户可选「下载并安装」或「忽略这个版本」；设置里能关掉启动自动检查。

## 下载与安装

- `dio` 把 APK 下载到 App 私有目录 `getApplicationDocumentsDirectory()/peiban-update.apk`，带进度。
- `open_filex` 用 `application/vnd.android.package-archive` 调起系统安装界面。
- Android 权限：`REQUEST_INSTALL_PACKAGES`（`AndroidManifest.xml` 已声明）。
- `androidx.core.content.FileProvider` + `res/xml/provider_paths.xml` 让安装器能读私有目录里的 APK（Android 7+ 不允许直接暴露 `file://`）。
- 手机上第一次装更新包时，系统会弹「允许来自此来源的安装」，用户点允许即可。

## 本机自测升级链路

把 `version.json` 的 `build` 临时改成一个比当前 APK 更大的数（比如 `99`），推上去，
打开 App 就会看到更新条；点设置里「检查更新」能看到弹窗。测完改回来即可。
想测完整下载，把 `apk_url` 换成一个真实可下载的 APK 直链。

## 边界

- 自用 / 小范围分享版：**不做签名校验、不做断点续传、不做强制升级、不走应用商店**。
- `apk_url` 指向的是你自己仓库的 Release，别填来路不明的地址。
- 新版 APK 用的是 debug 签名（方便直接安装）；如果以后换了正式签名，旧版不能覆盖安装，需要先卸载。
