# 本地打包指南（Android 为主，iOS 附说明）

面向「自用 / 小范围分享」。全程在本机完成，不需要服务器，不需要开发者账号（iOS 除外）。

> 在线升级的版本清单与发布流程见 [升级发布说明.md](升级发布说明.md)。

---

## 一、环境依赖（Windows，一次性装好）

### 1. Flutter SDK

```bash
# 方式 A：下载官方 zip（推荐，最省事）
#   https://docs.flutter.dev/get-started/install/windows
#   解压到 C:\src\flutter，然后把 C:\src\flutter\bin 加进系统 PATH

# 方式 B：git 拉 stable
git clone https://github.com/flutter/flutter.git -b stable C:\src\flutter
# 同样把 C:\src\flutter\bin 加进 PATH
```

加完 PATH 后**重开一个终端**，验证：

```bash
flutter --version
dart --version
```

国内网络慢可以配镜像（PowerShell）：

```powershell
$env:PUB_HOSTED_URL = "https://pub.flutter-io.cn"
$env:FLUTTER_STORAGE_BASE_URL = "https://storage.flutter-io.cn"
```

### 2. Android Studio + Android SDK

装 [Android Studio](https://developer.android.com/studio)，安装时勾选 Android SDK、Android SDK Platform、Android SDK Build-Tools。装完打开 **SDK Manager → SDK Tools**，勾上 **Android SDK Command-line Tools (latest)**。

然后接受许可：

```bash
flutter doctor --android-licenses   # 一路 y
flutter doctor -v                   # 看到 Android toolchain 打勾即可
```

### 3. JDK

**装 JDK 21**（本机实测 Temurin 21.0.13+9）。Flutter 3.50 生成的工程是 AGP 9.3.1 + Gradle 9.5.0，用 JDK 17 容易踩版本坑，21 最稳。装完设 `JAVA_HOME` 指向它，并把 `%JAVA_HOME%\bin` 加进 PATH。

本机这套实测可用的组合：**Flutter 3.50.0 / Dart 3.14.0 · JDK 21 · Android SDK 36（compileSdk 36、minSdk 24）· Gradle 9.5.0 · AGP 9.3.1**。工具链装在 `C:\Users\Administrator\.peiban-tools\`。

## 二、平台目录已在仓库，不用再生成

`android/` 目录已经生成好并提交进仓库，通知权限和 desugaring 两处补丁也已经打好了，**不要重复跑 `flutter create`**——它可能覆盖 `lib/main.dart`。万一跑了：

```bash
git status
# 若 lib/ 下有文件被改动：
git checkout -- lib/
```

换一台新电脑时只需改 `android/local.properties` 里两个本机路径（这个文件在 `.gitignore` 里，不进仓库）：

```properties
sdk.dir=C:\\path\\to\\android-sdk
flutter.sdk=C:\\path\\to\\flutter
```

补丁内容见 [Android配置补丁.md](Android配置补丁.md)（备查，从零重建平台目录时才需要照做）。

> 只有想连 iOS 目录一起生成时（代码本身跨端，Windows 上编不了 IPA）才需要：
> `flutter create --platforms=ios --project-name peiban_app --org com.dayouai.peiban .`

## 三、打 Android APK

```bash
flutter pub get
flutter build apk --release
```

成品在：

```
build/app/outputs/flutter-apk/app-release.apk
```

直接把这个文件发给朋友就能装（对方手机开「允许安装未知来源应用」即可）。

### 真机安装

```bash
# 手机开 USB 调试，连上电脑
adb devices                 # 确认能看到设备
adb install -r build/app/outputs/flutter-apk/app-release.apk
```

或者更简单：

```bash
flutter install
```

### 关于签名（自用可跳过）

没配 release 签名时，`flutter build apk --release` 会用 Flutter 自带的 debug keystore 签名，**APK 能正常安装使用**，只是不能上架应用商店。自用 / 小范围分享完全够，可以不做下面这步。

要是想给 APK 一个固定身份（以后升级覆盖安装更稳、不会因换机器签名不一致而装不上），配一次正式签名：

**① 生成 keystore**（放在项目外，别提交进仓库）：

```bash
keytool -genkey -v -keystore C:\Users\你的用户名\peiban.jks ^
  -keyalg RSA -keysize 2048 -validity 10000 -alias peiban
```

**② 新建 `android/key.properties`**（已在 `.gitignore` 里，不会入库）：

```properties
storePassword=你设的库密码
keyPassword=你设的key密码
keyAlias=peiban
storeFile=C:\\Users\\你的用户名\\peiban.jks
```

**③ 在 `android/app/build.gradle.kts` 的 `android {` 之前加：**

```kotlin
val keystoreProperties = java.util.Properties()
val keystorePropertiesFile = rootProject.file("key.properties")
if (keystorePropertiesFile.exists()) {
    keystoreProperties.load(java.io.FileInputStream(keystorePropertiesFile))
}
```

**④ 在 `android {` 里面加 signingConfigs，并让 release 用它：**

```kotlin
signingConfigs {
    create("release") {
        keyAlias = keystoreProperties["keyAlias"] as String
        keyPassword = keystoreProperties["keyPassword"] as String
        storeFile = file(keystoreProperties["storeFile"] as String)
        storePassword = keystoreProperties["storePassword"] as String
    }
}
buildTypes {
    release {
        signingConfig = signingConfigs.getByName("release")
    }
}
```

> ⚠️ `.jks` 和 `key.properties` 千万别提交进 GitHub，丢了密码就没法给 App 发升级版了。

## 四、iOS IPA（V1 不做，留个完整口径）

Dart 代码是跨端的，`flutter create --platforms=android,ios .` 能生成 iOS 目录，但 **Windows 上编不出 IPA**——必须有一台 macOS + Xcode。

在有 Mac 的机器上：

```bash
sudo gem install cocoapods
cd ios && pod install && cd ..
flutter build ipa
# 成品：build/ios/ipa/*.ipa
```

装到真机需要满足其一：

- **Apple Developer 账号**（个人/公司年费）＋ 在 Xcode 里选 Team、勾 Automatically manage signing，用 Development/Ad Hoc 描述文件装；
- **TestFlight**：上传后加测试员，最多可小范围分发给外部测试者。

没有证书或 TestFlight，IPA 装不上普通 iPhone。这一条是苹果的限制，不是代码问题。

## 五、高频报错排查

| 报错 / 现象 | 原因 | 怎么办 |
|---|---|---|
| `cmdline-tools not found` | 没装 Android SDK Command-line Tools | Android Studio → SDK Manager → SDK Tools → 勾 **Android SDK Command-line Tools (latest)** → 再跑 `flutter doctor --android-licenses` |
| `requires coreLibraryDesugaring to be enabled` | 通知插件需要 Java 8 时间 API 脱糖 | 按 [Android配置补丁.md](Android配置补丁.md) 第 2 步加 `isCoreLibraryDesugaringEnabled = true` 和依赖 |
| `Gradle build failed` / 依赖下载卡住 | Gradle 缓存或网络 | `flutter clean` → `flutter pub get` → 重编；国内可配 `PUB_HOSTED_URL` 镜像 |
| `Android license status unknown` | 没接受 SDK 许可 | `flutter doctor --android-licenses`，一路 `y` |
| 通知不弹（Android 13+） | 没授权或清单没声明 | 确认 Manifest 有 `POST_NOTIFICATIONS`；系统设置里给 App 开通知；代码已在 `ProactiveService.requestPermission()` 里申请 |
| **通知一直不响（国内安卓最常见）** | 厂商省电策略杀后台 | 系统设置里给 App 开「自启动」「允许后台运行」「忽略电池优化/无限制」，小米/华为/OPPO/vivo 各自位置不同，搜「电池优化」最快 |
| 选图闪退 / 报权限错 | 部分 ROM 的照片选择器差异 | Manifest 补 `READ_MEDIA_IMAGES`（见补丁文档第 1 节末尾） |
| DeepSeek 返回 401 | Key 填错、复制带了空格、或没余额 | 设置页重填，检查前后空格（代码已 trim），去 platform.deepseek.com 看余额 |
| 聊天回复中文乱码 | 响应解码方式不对 | 代码已用 `utf8.decode(resp.bodyBytes)` 处理，不用改 |
| 点通知打开 App 没生成主动消息 | 没填 Key（代码会静默跳过） | 设置页填 Key；另外确认是从通知点开的，不是手动打开 |
| `CocoaPods not installed` | iOS 缺依赖管理 | `sudo gem install cocoapods` |
| `Provisioning profile doesn't match` | iOS 签名不匹配 | Xcode → Signing & Capabilities → 选对 Team → 勾 Automatically manage signing |
| `flutter create` 后 App 变成计数器模板 | `lib/main.dart` 被覆盖 | `git checkout -- lib/` 还原 |
| `sdkmanager` 跑了很久一动不动 | 卡在「Accept? (y/N)」许可交互，非交互终端会永远等 | 用 `yes \| sdkmanager --licenses` 喂 `y`，或先把许可 hash 写进 `android-sdk/licenses/android-sdk-license` |
| `Failed to find package 'platforms;android-37'` | Android 37 平台包尚未发布 | 装 `platforms;android-36` + `build-tools;36.0.0`；通知插件用 22.x（compileSdk 36），别用要求 37 的 23.x |
| `zonedSchedule` 报「Too many positional arguments」「uiLocalNotificationDateInterpretation isn't defined」 | 通知插件 20.0.0 起位置参数全改命名参数，19.0.0 起删了 iOS 那个参数 | 仓库代码已按 22.x 适配：`id: / title: / body: / scheduledDate: / notificationDetails:`，且不再传该参数 |
| `initializeTimeZones isn't defined` | timezone 包把初始化函数挪到了 `data/latest.dart` | `import 'package:timezone/data/latest.dart' as tzdata;` 再调 `tzdata.initializeTimeZones()` |
| Gradle 报 JDK 版本不够 / AGP 起不来 | 用了 JDK 17 配 AGP 9.x | 换 JDK 21 并设 `JAVA_HOME` |
| `requires desugar_jdk_libs version to be 2.1.4 or above` | 脱糖库版本写低了（通知插件 22.x 有硬要求） | `build.gradle.kts` 里改成 `coreLibraryDesugaring("com.android.tools:desugar_jdk_libs:2.1.4")` |

## 六、边界提醒（说清楚，免得白等）

1. **安卓 APK 可以直接装**，自用和发给朋友都没问题，不需要任何账号。
2. **iOS IPA 必须有苹果开发者证书或走 TestFlight** 才能装到真机，且必须在 macOS + Xcode 上打包，Windows 做不了。
3. 这里只做**本地开发与本地打包**，不含应用商店上架、资质审核、隐私合规审查、内容审核后台——你定位是自用 / 小范围分享，本来也不需要。
4. **API Key 不随 APK 走**：每个用它的人填自己的 Key。别把 Key 截图发人、别提交进仓库。
5. 仓库里的代码已在本机用 **Flutter 3.50.0 / JDK 21 / Android SDK 36** 实际编译验证过。换环境时若 `flutter pub get` 提示包版本冲突，按提示把 `pubspec.yaml` 里的 `^x.y.z` 微调到当时最新稳定版即可；`pubspec.lock` 已提交，同版本环境下能复现。
