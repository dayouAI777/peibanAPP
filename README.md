# 陪伴 · peibanAPP

一款自用的 AI 虚拟陪伴 App：自由写一段描述，让 AI 帮你把「这个人」补完整，然后像发微信一样聊天；角色记得住你们的事，会带表情，也会偶尔主动找你。

- **大模型**：DeepSeek（`deepseek-chat`，OpenAI 兼容格式）
- **API Key**：自己填、只存本机；**配好并测试通过后才准进人设**
- **人设**：全局唯一，**定稿后不可修改**，只能删除重建
- **人物参考图**：自己从相册上传，不接文生图服务
- **在线升级**：Git 仓库里的 `version.json` 就是升级后台，不需要服务器
- **目标平台**：Android（Dart 代码跨端）
- **定位**：自用 / 小范围分享，**不商用**

> 仓库已含完整 Android 工程，clone 下来装好 Flutter 就能编译。
> 当前版本 **1.4.3+9**，实测工具链：Flutter 3.50.0 / Dart 3.14.0 · JDK 21 · Android SDK 36 · Gradle 9.5.0 · AGP 9.3.1。

---

## 启动顺序（这是硬规矩）

```
配置页：填 API Key → 点「测试链接」真发一次请求
   ↓ 通了才放行
人设页：自由输入 → AI 解析、查缺补漏 → 补齐 → 定稿
   ↓ 定稿后不可改
人设卡 → 聊天页
```

没测通就进不了人设页，免得定好人设才发现聊不了。

## 人设唯一，性格不会变

用户自由输入，AI 负责解析成 **12 个维度的人设空间**（名字、身份、外貌、性格、说话方式、关系、称呼、共同经历、生活习惯、在意的事、雷区、小动作），并诚实指出还缺什么、该怎么补。**每条改进意见下面直接带一个输入框**，就地填，全部填完点一次「填好了 · 让 AI 重新解析」，不用对照着跑到上面重写。可以一轮一轮补，直到 **7 个必填维度齐了**才能定稿——齐不齐由本地规则判定，不信任模型自己报的完成度。

定稿后**性格部分只读留档、没有任何编辑入口**。想换性格只有一个办法：删除重建（会清空聊天、摘要、行为手册，配置保留）。**头像和昵称属于外观，定稿后仍可修改**：人设卡或设置页 →「修改头像与昵称」。

> 旧版本建的角色没有完整人设空间，会提示删除重建一次。

## 千句上下文，超出的压缩

- 本地数据库**全量保存**每一句，不丢。
- 记忆窗口默认 **最近 1000 句**（设置里 200~5000 可调）。
- 每次请求不是把 1000 句原文全塞过去（那样又慢又贵、还会撞模型上下文上限），而是分层：
  - **system**：人设 + 行为手册 + 旧对话压缩摘要 + 表情规则
  - **messages**：最近若干条原文，按字符预算从新往旧取（上限 60 条 / 12000 字）
- 更早的对话按 **50 条一批**交给 AI 压成客观摘要，缓存进本地库，**每条只压一次**，之后永久带着。窗口外的历史也不丢，只是以摘要形式存在。

## 用户行为记录手册

宁可不记，也不乱记。AI 先判断「值不值得长期记住」，本地还有一层**一票否决的硬规则**：

| 规则 | 内容 |
|---|---|
| 只从用户的话里抽 | 绝不从 AI 自己的回复里找「用户习惯」 |
| 类别白名单 | 稳定偏好 / 生活习惯 / 身份事实 / 重要关系 / 明确好恶 / 反复模式 / 重要日期 |
| 置信度 | < 0.75 丢弃 |
| 长度 | < 6 字或 > 120 字丢弃 |
| 隐私 | 证件、银行卡、密码、验证码、手机号、详细住址等一律不记（含 11 位以上连续数字） |
| 临时性 | 含「今天/刚才/这次…」且没有「每次/总是/一直/习惯…」等稳定标记 → 丢弃 |
| 依据 | 必须给出用户原话 evidence，没有依据丢弃 |
| 去重 | 与已有条目包含关系或字符重合 > 0.8 丢弃 |
| 上限 | 最多 60 条 |

每积累 6 条用户消息评一次。手册内容能在「设置 → 查看行为记录手册」里逐条查看、删除、清空，也能整个关掉。

## 表情

内置一套按情绪分组的表情库（开心 / 撒娇 / 想你 / 委屈 / 闹别扭 / 害羞 / 无语 / 日常），**同一套表情两边共用**：

- 聊天输入框旁的表情按钮 → 面板点选，插入到光标处；
- AI 回复：表情池和用法规矩写进 system prompt。**默认「常用」——几乎每条回复自然带 1 个小表情**（主动消息也带），放在句末、贴合情绪，不堆不滥用。设置里可选「不用表情 / 偶尔用 / 常用（默认）」。

## 对话清晰度

实测遇到过模型输出「一大段三百多字、词语乱拼、没有正常断句」的胡话。定位是三处叠加：随机度默认 1.25 偏高、旧记忆摘要无上限全塞进 system 把人设稀释、截断后的上下文可能从「接自己的话」开始。V1.3.0 全部收敛：

- 随机度默认 **0.8**、上限锁死 **1.0**（旧版存过 1.25 / 1.5 的会自动降下来，不用手动改）；
- 单次回复硬限 **220 tokens**，并在 system 里写死「一次 1~3 句、总共不超过 60 字、绝对不要长段落」；
- 行为手册最多带 20 条、旧事摘要累计 ≤ 3000 字，避免人设被稀释；
- 截断后的原文若以 assistant 开头就去掉；
- 表情**只能放整条消息末尾、最多 1 个**，不再插在句子中间。

## 对话风格（后台静默）

后台默默学习你平时怎么说话：句子长短、语气、口头禅、标点与表情习惯、说话节奏。每积累 8 条用户消息学一次，失败静默、不弹窗、不打扰；结果只存本机。

只描摹语言风格，**不记具体聊了什么、不记隐私**；注入 system 时明确「不改变角色人设」。它和「行为记录手册」分工不同：手册记事实与稳定习惯，这里只管对话节奏。设置页底部有一行说明，没有开关也没有入口，不用管它。

## 图片能力

**能了（V1.4.0 起）。** 聊天页输入框旁有相册 / 拍照入口，图片压成 base64 后按 OpenAI 多模态格式
（`content` 数组，text + image_url/data url）发给 `deepseek-chat`——它现在实际路由到 `deepseek-flash`
（DeepSeek-V4.1-Flash，支持图文、1M 上下文），所以不用改模型名。

- 最近 **4 张**图片随请求发原图，更早的只留 `[图片]` 文字标记，省 token
- 头像会压成 512px / q72 的「定妆照」插在会话最前当身份参考，加上人设里的外貌描述，
  她认得出照片里是不是自己（V1.4.2）
- 代价：图片会离开手机上传到 DeepSeek，约 1 厘一张

## 在线升级

**仓库是公开的**（`dayouAI777/peibanAPP`），App 匿名直读即可，不用填任何令牌。之前遇到 HTTP 404 是因为仓库设成了私有——GitHub 对未授权访问私有仓库一律返回 404，**不是网络问题**；改成 public 后 raw / contents API / Release 全部 200。

Git 仓库根目录的 `version.json` 是唯一版本源，App 启动或设置页手动检查时读它（raw 优先，失败退 GitHub contents 接口）。发现新版本 → 展示更新内容 → `dio` 下载 APK → 调起系统安装界面。可忽略某个版本、可关自动检查。

**不是推送**：仓库没有服务器，无法主动通知手机，是 App 自己来查（pull）。自动的只有「检查」，**下载和安装永远要手动点**。

**按钮在哪**：设置页 →「版本与升级」→ **「检查更新」**（结果会常驻显示在按钮下面）；首页人设卡底部也有一个。有新版时首页顶部会自动出现提示条。已是最新版时只会显示「已是最新版」，不会出现升级按钮。

**想实测升级**：装旧的 `v1.1.0` APK，启动会看到首页「有新版本 1.2.0」提示，点设置里「检查更新」→ 升级面板 → 下载安装。直接装 `v1.2.0` 则显示「已是最新版」。

发布流程见 [升级发布说明](docs/升级发布说明.md)。

## 快速开始

```bash
cd peibanAPP
flutter pub get
flutter build apk --release
# → build/app/outputs/flutter-apk/app-release.apk
```

换电脑时改 `android/local.properties` 里的 `sdk.dir` / `flutter.sdk`（该文件不进仓库）。**不要重复跑 `flutter create`**，它可能覆盖 `lib/main.dart`；万一跑了，`git checkout -- lib/` 还原。

## 第一次使用（手机）

1. 装 APK → 配置页填 DeepSeek API Key → 「测试链接」→ 「下一步」。
2. 人设页随便写，点「让 AI 读一遍」，按提示补，必填齐了点「定稿」。
3. 想让 TA 主动找你：设置里打开开关、选条数和时段，**给通知权限 + 关掉电池优化**（国内安卓不关这个通知基本不响）。
